# Task Archetype Matrix

| Archetype | Example | Main dimensions |
|---|---|---|
| POWER | Strom / Technik | progress, risk |
| SETUP | Licht-/Bühnenaufbau | progress, reward |
| TIMED | Kabelweg unter Zeitdruck | progress, reward |
| RESOURCE | Ersatzteilkiste | progress, reward |
| SOCIAL | Einlass / Koordination | progress, reward |
| RISK | Notstromtest | progress, risk, reward |

Ability selection intersects with Task tags to activate modifiers.

This keeps content extensible and prevents a task engine full of per-ability branches.
